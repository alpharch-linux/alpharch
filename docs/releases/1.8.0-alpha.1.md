# Alpharch 1.8.0-alpha.1 — live desk public preview

This release delivers the rebuilt chart desk through the public installation
and update path. It is a preview for charting, analysis and replay feedback.

## Open the new desk

Install from alpharch.org or run `alpharch update`, then open **Alpharch Live
Desk**, press **SUPER+ALT+V**, or run `trade-workspace`. Check `alpharch version`
for `1.8.0-alpha.1`. The former canvas remains available through the advanced
engine/replay tools. Existing user-defined desk rooms are preserved; they can
continue opening an older tool until the user changes that room's command.

## Included

- Bitcoin chart/heatmap/tape, independent BTC/ETH/SOL overview, single-chart and
  blank starting desks; editable saved layouts and recovery after switching.
- Candles, heatmap, footprint, profile, ladder and tape; exact tick formatting,
  chart/price/pane zoom and pan, drawings, searchable indicators and settings.
- Public Coinbase/Kraken spot and Hyperliquid perpetual BTC/ETH/SOL feeds;
  optional Deribit options context and source/status visibility.
- Local recording/replay with several recordings on one clock; sampled depth
  is labeled as Level 2, not individual-order MBO or every book event.
- Native chart windows, Omarchy tiling and saved monitor routing.
- Existing calendar, basic morning brief, journal and user-owned Claude CLI.
- Read-only IBKR bridge and precise futures-file importer, with the access
  limitations below. No real broker orders are supported.

## Validation and limits

Offline checks passed: 38 original shell cases; 112 Python tests with one
optional SDK-dependent test skipped; JavaScript chart precision, navigation,
indicator and starting-layout suites; repeated full/no-theme/commands-only
installation and uninstall with foreign-file protection. Brain code is
unchanged; its deterministic tests passed without invoking a model.

A clean, disposable-home installation of this release verified the version,
app-menu target, native-launcher URL and all eight served desk assets. Live
checks passed for all nine Coinbase/Hyperliquid/Kraken × BTC/ETH/SOL streams
on 6 September 2026, including fresh books, trades and historical candles.
The browser-launch process in that installation check was stubbed.

No signed-in IBKR/CME acceptance, physical second-monitor/hotplug acceptance
or long-duration trading-session soak is claimed. Rithmic/CQG
adapters and the paid hosted Desk Brain service are not implemented.

Report the version, affected feed/contract, steps and errors through GitHub
issues. Keep account credentials and private journal entries out of reports.
