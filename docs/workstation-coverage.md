# Workstation implementation and acceptance

Updated 2026-09-06. This local development build is reviewable and installable. Implementation tests, actual public-feed tests, and unavailable licensed-account/hardware acceptance are distinguished below. Nothing here asserts universal broker compatibility or exchange-accurate simulation.

| Area | Implemented and checked | Practical boundary |
|---|---|---|
| Public chart data | Coinbase and Kraken BTC/ETH/SOL USD spot; Hyperliquid BTC/ETH/SOL perpetuals; nine actual trade/book/history streams checked | Binance regional restrictions remain; exchange identities are never blended |
| Precision | Decimal ingestion, native metadata ticks, exact exchange times, real-time axis spacing, OHLC/volume inspection, grouping conservation | Derived canvas calculations use JS floating point; source strings remain available in tape/inspection |
| Navigation | Cursor-anchored time zoom, independent price/pane zoom and pan, axis drags, box zoom, Fit/Auto/Live, keyboard navigation, exact UTC/price fields | Available captured/history range only |
| Views and bars | Candles, heatmap, footprint, volume profile, depth ladder, tape; time, trade-count, traded-volume and native-tick range bars | Event bars use retained prints; completing prints are whole; sequential slots prevent same-timestamp overlap; exact exchange times remain in inspection; bar numbers are relative to retained capture |
| Drawing tools | Horizontal levels, trends, rays, rectangles, Fibonacci, notes, measurement; draggable endpoints; exact editable coordinates; hide/remove; 50-step undo/redo | Undo is per current chart session; saved geometry is portable in desk JSON |
| Indicators | Searchable SMA/EMA/Bollinger Bands/stochastic/captured VWAP/RSI/MACD/ATR/volume/delta/CVD; parameter/color/weight/pane settings; study templates | Historical OHLCV and TWS trades do not provide aggressor delta; missing values remain unknown |
| Native workspace | Independent named Omarchy app windows; chart resizing/tiling; saved workspace/monitor routing; missing-monitor fallback; original existing windows retained | Three real native windows verified tiled/nonfullscreen on one monitor; physical second-monitor/hotplug acceptance unavailable |
| Linking and markets | Nine-source market picker; symbol groups and compatible cursors; cross-window public-symbol links | Same browser profile/origin required; each IBKR window owns its gateway connection |
| Appearance | Bright candles, luminous neutral depth shading, directional edge profiles, padded footprint cells, separate study colors, custom directional colors, grid/heat/glow controls, hollow candles, motion toggle | Real-data screenshots include sparse periods where the source supplied few trades |
| Recording/replay | In-desk exact-trade JSONL capture; sampled top-100 available depth; multiple source recordings on one paused/playing exchange-time clock; step/seek/speed; prior live desk restored | 100 MB/500,000 events per desk replay. Depth is sampled L2, not full tick-depth or MBO. Older tapes use the advanced tool |
| Replay acceptance | Three real recorded streams replayed through all 838 events; exact final-event seek; source/tick/contract metadata; unknown-side futures round-trip tested | No rewinding of a separate paper execution ledger |
| Observations/options | Deterministic captured facts, expiring displayed-depth concentrations, grouped Deribit option OI, JSON export, source/time-stamped local journal notes | Options are grouped by expiry/put-call; never dealer positioning or trading signals. Optional requests stop when disabled |
| Desk Brain | Existing user-owned Claude CLI narration/help; deterministic grounding and offline fence tests retained | Brain code unchanged; no model invocation added to observations, no live adversarial model run in this build |
| Connections | Provider-specific catalog/help, public-feed chart buttons, memory-only Kraken/Deribit/Binance read-only account APIs | Account adapters tested with protocol fixtures, not real credentials. No orders, withdrawals or credential persistence |
| IBKR futures | Official optional SDK bridge; local Linux gateway form with custom ports; resolved dated contracts; exchange market rules; quote/trade/L2 callbacks; errors, delayed/frozen labels and disconnect invalidation | Official-SDK decoder tests pass. Real signed-in gateway/account/exchange entitlement acceptance unavailable |
| Other futures providers | CQG/Rithmic access requirements; registered-OAuth routes for Tradovate/TradeStation/tastytrade; broker-to-provider distinctions; official guides | Their vendor adapters/registrations/conformance are not implemented or falsely claimed by the catalog |
| Futures files | Existing precise Databento trade/MBP CSV importer; explicit contract/tick metadata; advanced replay | Licensed files must be supplied by their owner |
| Manual execution | Existing optional advanced paper ledger and ticket; disabled by default; idempotent/partial-fill tests | Simulation only, whole-unit ticket, displayed-liquidity model without queue/fees/latency; no live broker execution adapter |
| Lifecycle/security | Per-browser private account ownership; API secret redaction; private redirect refusal; serialized monotonic Kraken nonces; shared public streams close after final chart/recorder owner leaves | Broker software/sign-in stays outside Alpharch; loopback-only service |
| Install/update/remove | One-command overlay/app entry; optional theme/branding/bindings; repeat-install/uninstall and foreign-file protection; existing update path | Full desktop overlay not applied to this host during review; journal/config remain user-owned |
| Starting desks | First-launch Bitcoin chart/heatmap/tape, independent BTC/ETH/SOL overview, single chart and blank choices; previous desk recovery; responsive tile geometry; appearance and named-layout preservation | Public Coinbase spot templates; recorded depth and flow warm up from actual events; existing desks are not replaced on launch |
| Persistence/uptime | Enabled user preview service; automatic/named browser layouts; import/export; native window identities | Service restart resets memory capture, not saved layouts or recordings |
| Tests | Full offline suite, source math, replay/recording, SDK callbacks, sessions/lifecycle, security, browser controls and fake-HOME installs | Long-duration soak, different hardware and actual licensed accounts remain separate acceptance evidence |

See [live desk guide](live-desk-guide.md), [connection readiness](connections-development.md), [IBKR bridge](ibkr-bridge.md), and [official platform research](charting-research-2026-09-05.md). These boundaries are explicit release limitations, not representations that an unavailable vendor service was tested.

Bollinger Bands use the selected price source, an editable 2–200-bar SMA and 0.1–10 population standard deviations (default 20/2). Middle, upper and lower lines have independent colors. Stochastic uses a 2–200-bar high/low lookback and separate 1–200-bar SMA smoothing for %K and %D (default 14/3/3); a zero range is neutral 50. Both leave warm-up values empty, support price overlay or a separate pane, and retain settings/colors in study templates and desk layouts. Stochastic panes default to 0–100.
