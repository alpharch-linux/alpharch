# Chart keyboard workflows

The approved visual pass and independent chart themes now ship with a focused-window command bridge. A fixed action allowlist is routed over the existing loopback WebSocket server. Runtime discovery files are private to the current user. The compositor focus is rechecked by the receiving server; unregistered or duplicate chart identities fail explicitly. Commands require an acknowledgement from the selected chart. There is no order execution action.

Super+Alt+U opens search. Super+Alt+Shift plus N/I/T/D/P/S/O/C/R/H/L/Z opens the documented chart operations. Ctrl+K is the in-app equivalent. Drawings can be selected from search and placed with Alt+arrows and Enter, retaining native-tick snapping, existing validation, undo, and per-chart persistence. Freehand paths use Enter to begin/end and arrows between. Existing dialogs retain Tab/Shift+Tab and Escape navigation. Classic popup menus focus their first action when opened.

Validation includes focused routing, recipient-only acknowledgement, focus mismatch, duplicate windows, rejected actions, disconnect cleanup, private discovery file permissions, drawing/interval calculations, source isolation, themes, native layouts and repeated install/uninstall checks. Browser checks exercised search, interval dialog focus, keyboard drawing placement and undo, and indicator library access.
